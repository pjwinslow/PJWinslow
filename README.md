# Peter J. Winslow — academic website

Personal academic website, built with [Hugo](https://gohugo.io) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

- Content: `content/_index.md` (bio), `data/*.yaml` (papers, research, talks, teaching, service, awards), `hugo.yaml` (name, contact, menu)
- Design: `assets/css/style.css` and `layouts/`
- Files: `static/files/cv.pdf`, `static/images/` (headshot, lab photo, PJW monogram)

See [UPDATING.md](UPDATING.md) for how to edit the site.

To publish: in the repository's **Settings → Pages**, set **Source** to **GitHub Actions**, then push to `main`.
